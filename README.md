# Unofficial Blood Magic Neoforge Rewrite

This is the wrong place if you're here to get the mod. Go to Curseforge or Modrinth or something.

If you're here to contribute: <br>
Find an issue you want to work on, that is not assigned to anyone and doesnt have an open PR attached to it.
If there is an open PR for it but it hasnt been worked on in a long time its free game as well.

When you found such an issue create a fork of the `rewrite-neo` branch to work on and create a draft PR and let github know which issue its for by putting `closes #[issue number]` in the description.

You can add as many commits to the PR as you like, they will all be squashed together before merging. Commits also let everyone know that its actively being worked on.
If you dont want to continue working on it please close the PR yourself or add a comment to it that you stop
